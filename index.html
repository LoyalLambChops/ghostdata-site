05 / A FEW THINGS TO KNOW

Before you jump in.

Honest answers about where GhostData stands today.

How do I download and run it?

Download GhostData for Windows and run the installer. That single file includes Python and .NET, creates a Start Menu shortcut and offers a Desktop shortcut. You do not need a separate ZIP or developer tools. This beta is unsigned; Windows may warn or block it under your security policy. Release notes, SHA-256 checksums and the optional portable ZIP are on GitHub.

Does my match data leave my computer?

Normal tracking keeps your history on your machine. There is no GhostData account or cloud match-history service. The explicit Update button can contact GitHub for GhostData releases; game definitions are imported from the installed client. Read our privacy and project information.

Is it free and open-source?

Yes—GhostData’s original software is licensed under MIT, allowing use, modification and redistribution with the required notice. Third-party components retain their own licenses. The application source and releases are public on GitHub.

Which games and systems are supported?

GhostData focuses on Hearthstone Standard on Windows 11 x64. The installer includes Python and .NET, so players won’t need to build the app. GhostData configures Power.log logging and imports card definitions from your installed game automatically. If Hearthstone was already open when logging was first enabled, it may need one restart. Other formats and operating systems are outside the current scope.

Does “lightweight” mean measured against other trackers?

Lightweight is a design goal: local processing, a standard-library Python backend, and no always-running background service. A matched CPU and memory comparison has not been completed, so we aren’t claiming benchmark superiority.

How can I help?

Share questions, ideas or bug reports in Discord or email LoyalLambChops@gmail.com. You can also find me on Twitch. Describe what happened and what you expected. Review screenshots and logs for personal information before choosing to share them.
