05 / A FEW THINGS TO KNOW

Before you jump in.

Honest answers about where GhostData stands today.

Can I download it yet?

Not publicly yet. Version 1.3.0 is a packaging candidate being tested. Licensing, signing, clean-machine checks and remaining live-game acceptance come before a public release. The download link will appear here when it is ready.

Does my match data leave my computer?

Normal tracking keeps your history on your machine. There is no GhostData account or cloud match-history service. The explicit Update button can contact GitHub for GhostData releases; game definitions are imported from the installed client. Read our privacy and project information.

Is it free and open-source?

That’s the plan for the public release. GhostData is being built to be free and open-source. The application repository is currently private while the release and project license are finalized.

Which games and systems are supported?

GhostData focuses on Hearthstone Standard on Windows 11 x64. The installer includes Python and .NET, so players won’t need to build the app. Hearthstone Power.log logging must be enabled for tracking. Other formats and operating systems are outside the current scope.

Does “lightweight” mean measured against other trackers?

Lightweight is a design goal: local processing, a standard-library Python backend, and no always-running background service. A matched CPU and memory comparison has not been completed, so we aren’t claiming benchmark superiority.

How can I help?

Send questions, ideas or bug reports to LoyalLambChops@gmail.com. Describe what happened and what you expected. Review screenshots and logs for personal information before choosing to share them.
