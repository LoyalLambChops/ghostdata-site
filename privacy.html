The application

GhostData normally records and analyzes match history locally. It does not require a GhostData account and does not upload match history to a GhostData cloud service. Data is stored under your user profile in the GhostDataData folder unless you explicitly configure another location.

The Update button can check GitHub for GhostData releases. Public card definitions are read from your installed Hearthstone client and cached locally. The application does not fetch third-party card artwork. The current card-hover experience uses text.

Local history and logs are not encrypted by GhostData and may contain player names, game events, or file paths. You choose whether to share them for support. Updating or uninstalling the program does not erase the separate history folder.

This website

This is a static information site hosted on GitHub Pages. It has no account system, contact form, advertising scripts, analytics scripts, or third-party fonts. Images and site assets are served from the same site. Screenshot tabs change only what is shown in your browser; they do not store a profile or submit data.

GitHub operates the hosting infrastructure and logs visitors’ IP addresses for security purposes. See GitHub Pages data collection and the GitHub privacy statement. Contact links open your email application; email is handled by the providers you and the developer use.

Release status and rights

GhostData is in development. A free, open-source release is planned, but the application’s license and public source release are not yet finalized. There is no public application download on this site today.

The public website repository contains website content and approved product imagery only. It does not contain the private application source, personal match data, game logs, or private promotional files. Publishing this website does not grant a license to the unreleased application.
